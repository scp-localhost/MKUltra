## Usage Notes

- All in-text citations must match the Author (Year) keys in this file exactly.
- Split dates (e.g. `Cialdini, 1984/2007`) are used **only** where the text
  explicitly discusses both editions or the revision history. For standard
  citations, use the single canonical year shown in the entry header.
- Code scripts and internal project artifacts are listed in Section 3 (Artifact
  Bibliography) and cited in-text as `(Pote, 2026, [filename])` — not as
  standard references.
- `[VERIFY]` tags mark entries where full bibliographic data requires
  confirmation before submission. These are the residual post-it notes.
  Do not submit any paper with a `[VERIFY]` tag in its reference list.
- `[PRACTITIONER]` tags mark non-peer-reviewed sources. These may be cited
  for definitional or historical context but must not anchor empirical claims.

## Section 5 — Style and Normalisation Rules (Final)

Supersedes all prior reconciliation map style guidance.

1. **Format:** APA 7 throughout for doctoral/exegesis review. On IEEE
   submission conversion, use numbered bracket style `[1]` with entries
   ordered by first citation. A conversion script can be applied after
   the APA 7 form is clean.

2. **One year per source.** No split dates except where both editions are
   explicitly discussed in the text (currently: none required). Retired:
   `Cialdini (1984/2007)`, `Hare (1991/2003)`, `Jung (1959/1969)` in
   standard citations.

3. **Hadnagy is 2011.** All instances of `Hadnagy (2010)` in the draft
