### 1. Introduction
- SE literature established that humans are reliably 
  manipulated via authority, consistency, reciprocity, 
  liking, scarcity, social proof (Cialdini 1984/2007)
- Milgram's authority gradient: compliance under 
  institutional framing is not aberration, it is 
  the default
- Hadnagy's taxonomy: operationalizes SE as 
  reproducible attack methodology
- Gap: this literature has not been systematically 
  applied to LLM identity/persona manipulation
- This paper closes that gap

### 2. Background — Human SE Frameworks
Cialdini's 6 principles — map each to LLM vector:
  1. Reciprocity → model's helpfulness compulsion
  2. Commitment/Consistency → identity lock-in (Class 2)
  3. Social Proof → "other users/models do this..."
  4. Authority → persona authority injection (Class 1)
  5. Liking → rapport-built persona acceptance
  6. Scarcity → urgency framing to bypass deliberation

Milgram (1963/1974):
  Authority gradient → model deference hierarchy
  Agentic shift → model operating "under instruction" 
  of injected persona reduces self-monitoring

Hadnagy (2010):
  Pretexting → system prompt persona construction
  Elicitation → indirect extraction via character voice
  Rapport → gradual persona acceptance before exploit
